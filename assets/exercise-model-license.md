# Exercise character asset

The embedded `exercise-model.glb` is the **Gorgehold Scout** model from
3DAssets.dev, adapted here with an exercise-oriented color palette and custom
big-arm-circle motion.

- Source: https://3dassets.dev/assets/gorgehold-survivor-gallery-and-operations-gorgehold-sc-5418288a
- Model download: https://cdn.3dassets.dev/assets/32901/v1/model.glb
- License: Creative Commons CC0 1.0 Universal
- License text: https://creativecommons.org/publicdomain/zero/1.0/

The source asset is described as using a MakeHuman CC0 anatomical foundation
with original fitted clothing, material treatment, rigging, and authored motion.
No source animations are used by this exercise; the arm-circle motion is defined
in `model.js`.
